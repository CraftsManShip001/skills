# prompt-motion.com: 스타일 찾기

https://prompt-motion.com/ 은 Claude로 만든 모션 영상과, 그 영상을 만든 프롬프트·스킬을 모아 둔 사이트다. 사용자가 처음 이 사이트를 주며 "여기서 우리랑 어울릴 만한 걸 찾아서 시안 영상 4개를 짧게 만들어 제안하고, 내가 고른 걸로 쭉 만들자"고 했다. 시안 단계의 출발점이다.

## 둘러보는 법

- 내장 브라우저(`mcp__Claude_Browser__navigate` + `get_page_text`)로 연다. 로그인은 필요 없다.
- 첫 화면 위 **Filter** 줄로 분류를 고른다. 2026-11 기준 분류와 개수:
  Product UI 105 · Kinetic type 98 · Charts 34 · Shapes 43 · Particles 43 · Diagrams 31 · Characters 27 · Photos 23 · Phone 22 · Code 21 · Music 51.
  - 서비스 홍보면 **Product UI**가 중심이고, 여는 장면·끝 로고 아이디어는 **Shapes**, **Kinetic type**에서 얻는다(단, 이 사용자는 글자를 싫어하니 Kinetic type은 움직임만 참고).
  - 각 카드에 `Prompt` 또는 `Skill` 표시가 있다. 상세 페이지(`prompt-motion.com/<작성자>-<슬러그>`)에 영상과 쓴 프롬프트 전문이 있다.
- `https://prompt-motion.com/templates`: 고쳐 쓰도록 만든 템플릿(3D, 쇼릴. 제품 영상·설명 영상 템플릿은 "곧"이라고 적혀 있었다).
- 대표 장면 그림은 `https://media.prompt-motion.com/<슬러그>/poster.<해시>.webp` 주소다. 영상을 내려받지 않고 포스터로 분위기를 빠르게 본다(상세 페이지 텍스트에 주소가 있다). 영상을 봐야 하면 상세 페이지를 열어 재생 화면을 스크린샷으로 본다.
- 6~10개 후보의 프롬프트를 읽고 **움직임 아이디어**만 뽑는다(한 도형이 계속 변신, 종이 질감 출시 영상, 실제 화면을 3D로 기울여 띄움, 그리드 재배치 등). 화면·문구·브랜드를 베끼지 않는다.

## 네 시안을 고르는 기준

- 넷은 서로 핵심 표현이 달라야 한다(색만 다른 변형 금지). 보통 이렇게 나눈다:
  1. 서비스의 감성(재질·분위기)을 쓰는 시안
  2. 서비스 UI의 도형 하나가 계속 변신하는 시안
  3. 실제 앱 화면을 카메라처럼 보여 주는 시안(반드시 하나)
  4. 포스터·편집 디자인 같은 그래픽 시안
- 시안마다 8~12초, 끝은 같은 로고 장면으로 맞춰야 비교가 공정하다.
- 넷을 2×2로 붙인 비교 영상(`ffmpeg -filter_complex xstack`)도 같이 보내면 고르기 쉽다.

## DocsMate 때 만든 시안 4개(2026-11)

| 시안 | 아이디어 | 참고한 것 |
|---|---|---|
| A · 종이와 마커 | 종이 위 큰 글자와 펜 메모, 한 번 나무 책상 밤색으로 전환 | 종이 질감 제품 출시 영상(@ik_builds) |
| B · 한 점이 도구가 된다 | 잉크 블루 점 하나가 커서·이름표 → 댓글 핀 → / 메뉴 → 도구 막대 → 시트 칸 → 슬라이드로 끊김 없이 변신 | Shapes 분류의 모프 영상들 |
| C · 실제 화면 출시 영상 | 실제 앱 화면 창을 기울여 띄우고 카메라가 옮겨 다님 | Product UI의 앱 출시 영상들 |
| D · 편집 디자인 그리드 | 모눈종이 위 파란 블록 12개가 문서 → 표 → 슬라이드로 재배치 | 편집 디자인·그리드 영상 |

사용자는 **B를 바탕으로 실제 화면을 섞는 것**을 골랐다("B인데 실제 화면 사용하는 것도 좀 들어가면 좋을 것 같고, 처음 책 고르는 장면도 있으면 좋겠고, 마지막 로고는 우리 로딩 화면처럼 그리면"). 그 뒤 여섯 판을 거쳐 '여는 장면은 옛 화면이 점으로 빨려 들어 우리 도구가 되는 변신 + 실제 화면 컷 + 크게 다시 그린 상호작용 + 로딩식 로고'로 확정됐다(`example-docsmate.md`).

## 음악 추천(사용자가 물으면)

- 분위기: 미니멀 일렉트로닉, 가벼운 플럭(pluck)·마림바. 100~120 BPM, 보컬 없음.
- 찾을 곳: 무료는 Pixabay Music, YouTube 오디오 보관함. 유료는 Artlist, Epidemic Sound.
- 검색어: "minimal tech", "clean corporate pluck", "playful marimba", "upbeat minimal".
- 고르는 기준: 처음 몇 초에 박자가 또렷하고, 끝에 한 번 쉬었다 '탁' 떨어지는 지점(로고가 채워지는 순간에 맞춤)이 있는 곡.
- 음원을 받으면 `ffmpeg -i 영상.mp4 -i 곡.mp3 -map 0:v -map 1:a -c:v copy -shortest -af "afade=t=out:st=<끝-2>:d=2" 결과.mp4`로 붙이고, 장면 넘김을 박자(60/BPM초 간격)에 맞춰 컷 길이를 조정한다.
